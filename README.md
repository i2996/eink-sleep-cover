# 슬립 표지 (eink-sleep-cover)

리디·교보·밀리의서재·알라딘·예스24·Google Play 북 등 **어느 서점 앱으로 읽든**
지금 읽는 책의 표지를 이북리더기의 슬립(대기) 화면으로 바꿔 주는 안드로이드 앱입니다.
크레마 팔레트와 오닉스 Boox 팔마2를 염두에 두고 만들었습니다.

## 동작 방식

1. **제목 알아내기**: 접근성 서비스가 고른 독서 앱 화면에서 책 제목으로 보이는 글자를 읽습니다.
   (책 본문은 읽지 않고, 저장하거나 밖으로 보내지도 않습니다.)
2. **표지 찾기**: 그 제목으로 알라딘에서 표지(최대 500px)를 찾습니다.
   알라딘 TTB 키를 넣으면 공식 API로, 없으면 알라딘 검색 페이지 → Google 도서 순으로 찾습니다.
3. **슬립 이미지 저장**: 화면 해상도에 맞춰 그린 뒤 항상 같은 파일
   `<저장 폴더>/sleep_cover.png` 에 덮어씁니다.
   기기 설정에서 이 파일을 슬립 이미지로 **한 번만** 골라 두면, 책을 바꿀 때마다 내용만 바뀝니다.

한 번 받은 표지는 앱 안에 보관됩니다. 그래서 같은 책은 다음부터 **와이파이 없이도** 바로 바뀝니다.
처음 여는 책은 표지를 받아야 하므로 와이파이가 필요합니다. 와이파이가 없을 때 열었으면,
연결된 뒤 그 책을 다시 열면 자동으로 다시 시도합니다.

자동 감지가 안 되거나 틀리면:
- 앱을 열어 제목을 직접 검색하고 표지를 누르거나,
- 독서 앱의 **공유하기 → 슬립 표지** 로 책 정보를 보내면 바로 검색됩니다.

## 설치

1. 기기 브라우저로 이 저장소의 **Releases → latest** 에서 `eink-sleep-cover.apk` 를 받아 설치합니다.
   (설치가 막히면 "출처를 알 수 없는 앱 설치"를 허용)
2. 앱을 열고 순서대로:
   1. **저장 권한 허용** → "모든 파일 접근" 허용
   2. **접근성 서비스 켜기** → 목록에서 "슬립 표지" 켜기
      - 안드로이드 13 이상에서 회색으로 막혀 있으면: 설정 → 앱 → 슬립 표지 → 오른쪽 위 ⋮ → "제한된 설정 허용" 후 다시 시도
   3. **책 읽는 앱 고르기** → 쓰는 서점 앱 체크
3. 독서 앱에서 책을 열고, 화면을 한 번 탭해 위쪽 메뉴(책 제목이 보이는 바)를 띄웁니다.
   몇 초 뒤 "슬립 표지: 제목" 알림이 뜨면 성공입니다.

## 기기별 설정

### 크레마 팔레트
- 크레마는 내부 저장소의 **`Wallpaper`** 폴더에 있는 이미지만 슬립 이미지로 보여 줍니다.
  크레마에서는 저장 폴더가 자동으로 `Wallpaper` 로 잡힙니다. 자동으로 안 잡히면 앱에서 직접 `Wallpaper` 로 바꿔 주세요.
- 한 번 표지를 만든 뒤, 크레마 설정의 슬립 이미지에서 `sleep_cover.png` 를 고릅니다.

### 오닉스 Boox 팔마2
- 갤러리에 있는 이미지는 화면보호기로 고를 수 있습니다. 기본 저장 폴더는 `Pictures/SleepCover` 입니다.
- 한 번 표지를 만든 뒤, 화면보호기 설정에서 `sleep_cover.png` 를 고릅니다.

> 기기가 고른 이미지를 따로 복사해 두는 방식이면, 파일을 덮어써도 슬립 화면이 안 바뀔 수 있습니다.
> 그럴 땐 알려 주세요. 다른 방식으로 바꿔 보겠습니다.

## 빌드

기본 브랜치에 push하면 GitHub Actions가 APK를 빌드해 `latest` 릴리스로 올립니다.
업데이트 설치가 되도록 모든 빌드를 `signing/sleepcover.jks`(개인용 키)로 서명합니다.

## 리모컨 버튼

블루투스 리모컨(예: ShanWan Q36)의 버튼을 독서 앱에서 원하는 동작으로 바꿉니다.

1. 리모컨을 기기와 블루투스로 연결합니다.
2. 앱의 **리모컨 버튼 → + 버튼 추가**를 누른 뒤 리모컨 버튼을 한 번 누릅니다.
3. 그 버튼에 붙일 동작을 고릅니다: 다음/이전 페이지(탭 또는 넘기기), 스크롤, 메뉴, 뒤로 가기 등.

- "감시 중"인 독서 앱이 화면에 있을 때만 바뀌고, 다른 앱에서는 리모컨이 원래대로 동작합니다.
  단, "앱 열기"와 "와이파이 켜기/끄기"는 어디서든 동작합니다.
- 페이지 넘김은 화면 오른쪽/왼쪽을 대신 탭하는 방식이라 리모컨을 지원하지 않는 앱에서도 됩니다.
  앱이 탭 대신 넘기기만 받으면 "넘기기" 동작을 고르세요.
- 버튼을 눌러도 배우기 창이 반응하지 않으면, 그 버튼은 키가 아니라 마우스/터치 신호를 보내는 것이라 바꿀 수 없습니다.
  리모컨의 모드(키보드·게임패드 등)를 바꿔 보세요.
